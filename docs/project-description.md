# Описание проекта m-postel.ru

## Общая информация
**Сайт**: https://www.m-postel.ru  
**Тип**: Интернет-магазин постельного белья  
**CMS**: Bitrix Site Manager  
**Целевая аудитория**: Покупатели постельного белья и текстиля для дома

## Основные функции сайта

### 🛒 Электронная коммерция
- **Каталог товаров** - постельное белье, подушки, одеяла, пледы
- **Корзина покупок** - добавление, редактирование, удаление товаров
- **Оформление заказа** - выбор способа доставки и оплаты
- **Личный кабинет** - управление заказами, профиль пользователя

### 👤 Пользовательский функционал
- **Регистрация** - создание аккаунта
- **Авторизация** - вход в личный кабинет
- **Восстановление пароля** - сброс пароля через email
- **Профиль пользователя** - редактирование личных данных

### 🔍 Поиск и навигация
- **Поиск товаров** - поиск по названию, артикулу
- **Фильтрация** - по категориям, размерам, материалам, ценам
- **Сортировка** - по цене, популярности, новизне
- **Хлебные крошки** - навигация по разделам

### 📱 Адаптивность
- **Мобильная версия** - оптимизация для мобильных устройств
- **Планшетная версия** - адаптация для планшетов
- **Десктопная версия** - полная функциональность

## Структура сайта

### Главная страница
- Слайдер с акциями и новинками
- Популярные категории товаров
- Блок с преимуществами магазина
- Новости и статьи

### Каталог товаров
- **Категории**: Постельное белье, Подушки, Одеяла, Пледы, Аксессуары
- **Подкатегории**: По размеру, материалу, дизайну
- **Карточки товаров**: Фото, название, цена, краткое описание

### Страница товара
- Галерея изображений
- Подробное описание
- Характеристики (размер, материал, состав)
- Отзывы покупателей
- Рекомендуемые товары

### Корзина
- Список выбранных товаров
- Возможность изменения количества
- Расчет стоимости
- Применение промокодов

### Оформление заказа
- Выбор способа доставки
- Ввод адреса доставки
- Выбор способа оплаты
- Подтверждение заказа

### Личный кабинет
- История заказов
- Текущие заказы
- Личные данные
- Избранные товары

## Технические особенности

### Безопасность
- HTTPS протокол

### Производительность

## Критические бизнес-процессы

### 1. Покупка товара
1. Выбор товара в каталоге
2. Добавление в корзину
3. Переход к оформлению заказа
4. Заполнение данных доставки
5. Выбор способа оплаты
6. Подтверждение заказа

### 2. Регистрация пользователя
1. Переход на страницу регистрации
2. Заполнение формы данных
3. Подтверждение email
4. Активация аккаунта

### 3. Восстановление доступа
1. Переход на страницу восстановления
2. Ввод email
3. Получение письма со ссылкой
4. Создание нового пароля

## Ожидаемые проблемы для тестирования

### Функциональные проблемы
- Некорректная работа корзины
- Ошибки при оформлении заказа
- Проблемы с регистрацией/авторизацией
- Неправильная работа фильтров

### UI/UX проблемы
- Проблемы с адаптивностью
- Некорректное отображение в разных браузерах
- Проблемы с навигацией
- Медленная загрузка страниц

### Безопасность
- Уязвимости в формах
- Проблемы с валидацией данных
- Отсутствие защиты от брутфорса
- Утечки персональных данных
