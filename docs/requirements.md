# Требования к тестированию m-postel.ru

## Общие требования

### Цели тестирования
- Обеспечение качества пользовательского опыта
- Проверка корректности бизнес-процессов
- Выявление критических ошибок
- Подтверждение соответствия требованиям

### Область тестирования
- Функциональное тестирование
- UI/UX тестирование
- Кроссбраузерное тестирование
- Мобильное тестирование
- Тестирование производительности
- Тестирование безопасности

## Функциональные требования

### 1. Регистрация и авторизация
**Критерии приемки:**
- [ ] Пользователь может зарегистрироваться с валидными данными
- [ ] Пользователь может войти с корректными учетными данными
- [ ] Система блокирует вход с неверными данными
- [ ] Работает восстановление пароля
- [ ] Email подтверждается корректно

**Тестовые данные:**
- Валидные email адреса
- Пароли: минимум 6 символов
- Имя: минимум 2 символа

### 2. Каталог товаров
**Критерии приемки:**
- [ ] Отображаются все категории товаров
- [ ] Работает поиск по названию
- [ ] Фильтры применяются корректно
- [ ] Сортировка работает правильно
- [ ] Пагинация функционирует

**Тестовые сценарии:**
- Поиск существующих товаров
- Поиск несуществующих товаров
- Применение множественных фильтров
- Сортировка по цене (возрастание/убывание)

### 3. Корзина покупок
**Критерии приемки:**
- [ ] Товар добавляется в корзину
- [ ] Количество товара изменяется
- [ ] Товар удаляется из корзины
- [ ] Стоимость пересчитывается
- [ ] Корзина сохраняется между сессиями

**Тестовые сценарии:**
- Добавление одного товара
- Добавление нескольких товаров
- Изменение количества
- Очистка корзины

### 4. Оформление заказа
**Критерии приемки:**
- [ ] Форма заказа заполняется корректно
- [ ] Выбирается способ доставки
- [ ] Выбирается способ оплаты
- [ ] Заказ создается успешно
- [ ] Подтверждение отправляется на email

**Тестовые данные:**
- Валидные адреса доставки
- Корректные номера телефонов
- Существующие email адреса

### 5. Личный кабинет
**Критерии приемки:**
- [ ] Отображается история заказов
- [ ] Редактируются личные данные
- [ ] Просматриваются текущие заказы
- [ ] Работает выход из системы

## Нефункциональные требования

### 1. Производительность
**Критерии:**
- Время загрузки главной страницы: < 3 секунд
- Время загрузки каталога: < 2 секунд
- Время поиска: < 1 секунды
- Время добавления в корзину: < 1 секунды

### 2. Совместимость
**Браузеры для тестирования:**
- Chrome (последние 2 версии)
- Firefox (последние 2 версии)
- Safari (последние 2 версии)
- Edge (последние 2 версии)

**Устройства:**
- Десктоп (1920x1080 и выше)
- Планшет (768x1024)
- Мобильный (375x667, 414x896)

### 3. Безопасность
**Критерии:**
- [ ] HTTPS протокол используется везде
- [ ] Пароли не отображаются в открытом виде
- [ ] Сессии корректно завершаются
- [ ] Защита от SQL-инъекций
- [ ] Валидация всех форм

### 4. Доступность
**Критерии:**
- [ ] Контрастность текста соответствует стандартам
- [ ] Навигация работает с клавиатуры
- [ ] Alt-тексты для изображений
- [ ] Семантическая разметка HTML

## Критерии приемки

### Критические ошибки (Блокеры)
- Невозможность зарегистрироваться/войти
- Невозможность добавить товар в корзину
- Невозможность оформить заказ
- Полная недоступность сайта

### Высокий приоритет
- Ошибки в расчете стоимости
- Некорректная работа фильтров
- Проблемы с отображением в основных браузерах
- Ошибки в формах

### Средний приоритет
- Проблемы с адаптивностью
- Медленная загрузка страниц
- Некорректное отображение в старых браузерах
- Проблемы с доступностью

### Низкий приоритет
- Косметические дефекты
- Проблемы с отображением в редких браузерах
- Незначительные проблемы с производительностью

## Метрики качества

### Покрытие тестами
- Критические функции: 100%
- Основные функции: 95%
- Вспомогательные функции: 80%

### Стабильность
- Процент успешных тестов: > 95%
- Количество критических багов: 0
- Время исправления критических багов: < 24 часа

### Производительность
- Время отклика основных функций: < 2 секунд
- Доступность сайта: > 99.5%
- Время загрузки страниц: < 3 секунд
