# План функционального тестирования m-postel.ru

## Общая информация
**Цель**: Проверка всех функций сайта в соответствии с требованиями  
**Время выполнения**: 1-2 недели  
**Приоритет**: Высокий  
**Тип тестирования**: Функциональное, Интеграционное

## Области тестирования

### 1. Пользовательский функционал
- Регистрация и авторизация
- Личный кабинет
- Восстановление пароля
- Профиль пользователя

### 2. Каталог и поиск
- Навигация по категориям
- Поиск товаров
- Фильтрация и сортировка
- Карточки товаров

### 3. Корзина и заказы
- Добавление товаров в корзину
- Управление корзиной
- Оформление заказа
- История заказов

### 4. Оплата и доставка
- Выбор способа доставки
- Выбор способа оплаты
- Расчет стоимости
- Отслеживание заказа

## Тестовые сценарии

### Сценарий 1: Полный цикл покупки
**Приоритет**: Критический  
**Время**: 30-45 минут

**Шаги:**
1. **Регистрация пользователя**
   - Открыть сайт
   - Перейти на страницу регистрации
   - Заполнить форму валидными данными
   - Подтвердить email

2. **Поиск и выбор товара**
   - Войти в личный кабинет
   - Открыть каталог товаров
   - Найти товар через поиск
   - Применить фильтры
   - Выбрать товар

3. **Работа с корзиной**
   - Добавить товар в корзину
   - Изменить количество
   - Применить промокод
   - Перейти к оформлению

4. **Оформление заказа**
   - Заполнить данные доставки
   - Выбрать способ доставки
   - Выбрать способ оплаты
   - Подтвердить заказ

5. **Проверка заказа**
   - Получить подтверждение
   - Проверить заказ в личном кабинете
   - Проверить email уведомление

**Ожидаемый результат:**
- [ ] Все этапы выполняются без ошибок
- [ ] Данные сохраняются корректно
- [ ] Уведомления отправляются
- [ ] Заказ создается в системе

### Сценарий 2: Покупка без регистрации
**Приоритет**: Высокий  
**Время**: 20-30 минут

**Шаги:**
1. Открыть сайт без авторизации
2. Выбрать товар из каталога
3. Добавить в корзину
4. Оформить заказ как гость
5. Заполнить данные для доставки
6. Оплатить заказ

**Ожидаемый результат:**
- [ ] Покупка возможна без регистрации
- [ ] Данные гостя сохраняются
- [ ] Заказ оформляется корректно
- [ ] Предлагается регистрация после покупки

### Сценарий 3: Работа с личным кабинетом
**Приоритет**: Высокий  
**Время**: 15-20 минут

**Шаги:**
1. Войти в личный кабинет
2. Просмотреть историю заказов
3. Редактировать личные данные
4. Изменить пароль
5. Добавить товар в избранное
6. Выйти из системы

**Ожидаемый результат:**
- [ ] Все функции личного кабинета работают
- [ ] Данные обновляются корректно
- [ ] Безопасность обеспечивается
- [ ] Навигация интуитивна

### Сценарий 4: Поиск и фильтрация
**Приоритет**: Высокий  
**Время**: 20-25 минут

**Шаги:**
1. Открыть каталог товаров
2. Использовать поиск по названию
3. Применить множественные фильтры
4. Изменить сортировку
5. Перейти на следующую страницу
6. Очистить фильтры

**Ожидаемый результат:**
- [ ] Поиск работает быстро и точно
- [ ] Фильтры применяются корректно
- [ ] Сортировка функционирует
- [ ] Пагинация работает

### Сценарий 5: Обработка ошибок
**Приоритет**: Средний  
**Время**: 15-20 минут

**Шаги:**
1. Попытаться зарегистрироваться с невалидными данными
2. Ввести неверный пароль при входе
3. Добавить несуществующий промокод
4. Попытаться оформить заказ без товаров
5. Ввести невалидные данные доставки

**Ожидаемый результат:**
- [ ] Ошибки обрабатываются корректно
- [ ] Пользователь получает понятные сообщения
- [ ] Система не ломается
- [ ] Данные не теряются
