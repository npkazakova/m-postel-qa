# План смоук-тестирования m-postel.ru

## Общая информация
**Цель**: Проверка основных функций сайта для подтверждения его работоспособности  
**Время выполнения**: 1-2 часа  
**Приоритет**: Критический  
**Частота выполнения**: При каждом релизе, ежедневно

## Критерии успеха
- Все критические функции работают корректно
- Нет блокирующих ошибок
- Основные бизнес-процессы выполняются
- Сайт доступен и загружается

## Тестовые окружения
- **Продакшн**: https://www.m-postel.ru
- **Браузеры**: Chrome, Firefox, Safari, Edge
- **Устройства**: Десктоп, планшет, мобильный

## Тест-кейсы

### TC-SMOKE-001: Доступность главной страницы
**Приоритет**: Критический  
**Предусловия**: Интернет-соединение активно

**Шаги:**
1. Открыть браузер
2. Перейти на https://www.m-postel.ru
3. Дождаться полной загрузки страницы

**Ожидаемый результат:**
- [ ] Страница загружается без ошибок
- [ ] Отображается логотип сайта
- [ ] Работает главное меню
- [ ] Время загрузки < 5 секунд
- [ ] Нет ошибок в консоли браузера
