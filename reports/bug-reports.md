## Примеры отчетов

### BUG-001: Нельзя добавить товар в корзину
**Дата**: 2025-08-06  
**Приоритет**: Критический  
**Серьезность**: Блокер

**Описание**: При попытке добавить товар в корзину кнопка не реагирует на клик.

**Шаги для воспроизведения:**
1. Открыть каталог товаров
2. Выбрать любой товар
3. Открыть карточку товара
4. Нажать кнопку "Добавить в корзину"

**Ожидаемый результат**: Товар добавляется в корзину, появляется уведомление

**Фактический результат**: Кнопка не реагирует на клик, товар не добавляется

**Браузер**: Chrome 120.0.6099.109  
**URL**: https://www.m-postel.ru/catalog/postelnoe-bele/

---

### BUG-002: Ошибка валидации email при регистрации
**Дата**: 2025-08-06  
**Приоритет**: Высокий  
**Серьезность**: Высокая

**Описание**: При вводе валидного email адреса система показывает ошибку валидации.

**Шаги для воспроизведения:**
1. Открыть страницу регистрации
2. Ввести валидный email: test@example.com
3. Заполнить остальные поля
4. Нажать "Зарегистрироваться"

**Ожидаемый результат**: Форма принимается, регистрация проходит успешно

**Фактический результат**: Отображается ошибка "Неверный формат email"

**Браузер**: Firefox 119.0  
**URL**: https://www.m-postel.ru/register/
