# Тест-кейсы: Каталог товаров

## Общая информация
**Модуль**: Каталог товаров  
**Приоритет**: Высокий  
**Тип тестирования**: Функциональное, UI/UX, Производительность

## Тестовые данные

### Категории товаров
- Постельное белье
- Подушки
- Одеяла
- Пледы
- Аксессуары

### Фильтры
- **Размер**: 1.5 спальный, 2.0 спальный, Евро, Семейный
- **Материал**: Хлопок, Сатин, Бязь, Поплин
- **Цена**: 0-1000, 1000-3000, 3000-5000, 5000+
- **Цвет**: Белый, Голубой, Розовый, Зеленый

## Тест-кейсы

### TC-CAT-001: Открытие каталога товаров
**Приоритет**: Критический  
**Предусловия**: Открыта главная страница

**Шаги:**
1. Кликнуть на "Каталог" в главном меню
2. Дождаться загрузки страницы каталога

**Ожидаемый результат:**
- [ ] Страница каталога загружается
- [ ] Отображаются все категории товаров
- [ ] Время загрузки < 3 секунд
- [ ] Нет ошибок в консоли браузера

### TC-CAT-002: Навигация по категориям
**Приоритет**: Высокий  
**Предусловия**: Открыт каталог товаров

**Шаги:**
1. Кликнуть на категорию "Постельное белье"
2. Проверить отображение подкатегорий
3. Кликнуть на подкатегорию "2.0 спальный"
4. Проверить отображение товаров

**Ожидаемый результат:**
- [ ] Категории открываются корректно
- [ ] Отображаются соответствующие товары
- [ ] Хлебные крошки обновляются
- [ ] URL изменяется правильно

### TC-CAT-003: Поиск товаров
**Приоритет**: Высокий  
**Предусловия**: Открыт каталог товаров

**Шаги:**

4. Проверить результаты

**Ожидаемый результат:**

- [ ] Отображаются товары из сатина
- [ ] Результаты соответствуют запросу
- [ ] Время поиска < 2 секунд

### TC-CAT-004: Применение фильтров
