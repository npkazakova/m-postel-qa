# Тест-кейсы: Регистрация пользователей

## Общая информация
**Модуль**: Регистрация и авторизация  
**Приоритет**: Высокий  
**Тип тестирования**: Функциональное, UI/UX

## Тестовые данные

### Валидные данные
- **Email**: test@example.com, user123@gmail.com
- **Пароль**: Test123!, Password456!
- **Имя**: Иван, Мария, Александр
- **Телефон**: +7 (999) 123-45-67, 89991234567

### Невалидные данные
- **Email**: test@, @example.com, test.example.com
- **Пароль**: 123, password, 123456
- **Имя**: А, 123, !@#
- **Телефон**: 123, abc, +7 (999) 123-45

## Тест-кейсы

### TC-REG-001: Успешная регистрация с валидными данными
**Приоритет**: Критический  
**Предусловия**: Открыта страница регистрации

**Шаги:**
1. Заполнить поле "Email" валидным email
2. Заполнить поле "Пароль" валидным паролем
3. Заполнить поле "Подтверждение пароля" тем же паролем
4. Заполнить поле "Имя" валидным именем
5. Заполнить поле "Телефон" валидным номером
6. Поставить галочку "Согласен с условиями"
7. Нажать кнопку "Зарегистрироваться"

**Ожидаемый результат:**
- [ ] Регистрация проходит успешно
- [ ] Пользователь получает уведомление об успешной регистрации
- [ ] Отправляется email с подтверждением
- [ ] Пользователь перенаправляется на страницу входа или личный кабинет

## Критерии прохождения
- **Успех**: Все критические тесты пройдены
- **Частичный успех**: Пройдены критические + 80% остальных
- **Неудача**: Не пройден хотя бы один критический тест
