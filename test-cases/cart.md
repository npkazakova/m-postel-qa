## Тест-кейсы

### TC-CART-001: Добавление товара в корзину
**Приоритет**: Критический  
**Предусловия**: Открыт каталог товаров

**Шаги:**
1. Выбрать товар из каталога
2. Нажать кнопку "Добавить в корзину"
3. Проверить реакцию системы

**Ожидаемый результат:**
- [ ] Товар добавляется в корзину
- [ ] Счетчик корзины обновляется
- [ ] Появляется уведомление об успешном добавлении
- [ ] Кнопка меняет состояние на "В корзине"

### TC-CART-002: Открытие корзины
**Приоритет**: Критический  
**Предусловия**: В корзине есть товары

**Шаги:**
1. Кликнуть на иконку корзины в шапке сайта
2. Дождаться загрузки страницы корзины

**Ожидаемый результат:**
- [ ] Страница корзины открывается
- [ ] Отображаются все добавленные товары
- [ ] Показывается общая сумма
- [ ] Есть кнопка "Оформить заказ"

### TC-CART-003: Изменение количества товара

- [ ] Общая сумма обновляется
